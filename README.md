# Student Grade Tracker

A Java Swing-based application for managing student grades and analyzing student performance.

## Features

- Add Student Records
- Delete Student Records
- Grade Calculation (A, B, C, D, F)
- Average Marks Calculation
- Highest & Lowest Score Tracking
- GUI using Java Swing
- ArrayList Data Storage

## Technologies Used

- Java
- Java Swing
- OOP
- ArrayList
- Event Handling

## How to Run

```bash
javac *.java
java GradeTrackerGUI
```

## Project Structure

StudentGradeTracker
├── Student.java
├── StudentManager.java
└── GradeTrackerGUI.java
